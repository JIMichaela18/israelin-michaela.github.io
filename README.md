# Portfolio Website | Software Engineer

A responsive personal portfolio for Java and Spring Boot software engineer, showcasing professional experience, technical skills, projects, education, creative interests, and an AI-powered portfolio assistant.

**Live site:** [https://jimichaela18.github.io/israelin-michaela.github.io/](https://jimichaela18.github.io/israelin-michaela.github.io/)

## Highlights

- Professional experience and technical skills
- Education and achievements
- Creative interests and their connection to engineering
- Featured GitHub projects
- Two visual modes: technical and creative
- TOB, an AI portfolio assistant
- Downloadable resume
- Responsive navigation, scroll progress, animations, and accessibility considerations

## TOB — The Online Buddy

TOB answers questions about my skills, experience, projects, career break, and creative work.


**Chatbot backend:** [JIMichaela18/portfolio-chatbot](https://github.com/JIMichaela18/portfolio-chatbot)
